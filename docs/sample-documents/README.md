# Sample documents

Drop 2–3 real test documents here before the event — a lease, a bill, a
syllabus, a terms-of-service printout, anything with real text on it.
Having them ready ahead of time avoids scrambling for a demo document
during judging.

`scripts/seed_test_data.sh` uploads whatever is in this folder straight
to S3 to test the pipeline without going through the UI.

Nothing is bundled by default — add your own files here (PDF, PNG, or
JPG).
